# Figma UX Design Learning Hub

Welcome to the Figma UX Design Learning Hub, a curated educational resource for students and educators exploring the fundamentals of Figma and UX design principles.

## Site Overview

This GitHub Pages site provides:

- **Introductory guides** to Figma's interface and tools  
- **Hands-on exercises** for wireframing, prototyping, and UI design  
- **Embedded video walkthroughs** and demos  
- **Downloadable assets** and templates for student projects  
- **Conceptual overviews** of design principles and UX workflows

## Target Audience

Designed to support learners in higher education, especially those on digital and technology apprenticeship programmes. Ideal for:

- UX and UI design students  
- Digital design instructors  
- Self-learners exploring Figma
