# Vibe Code UX Testing

![vibe code ux testing](vibe-code-ux-testing.jpg)

## Overview

Three free tools take you from an idea to a prototype that real people have tested, without writing any code. You write the prompt in the **VibeProto Prompt Studio**, build the prototype in Claude using the **From Prompt to Prototype** guide, then run a guided user test in the **Desktop Tester**.

Each tool hands over to the next. The Studio's prompt asks Claude for a prototype that's ready for testing. The guide shows you how to turn Claude's reply into a single `index.html` file. The Desktop Tester then runs that file with your test participants and tells you how they got on.

The whole route works on the free Claude plan. It's designed for testing on a laptop or desktop.

## Step 3: Desktop Tester

**Desktop Tester** is a lightweight, static user-testing tool for desktop websites. It's designed to be hosted on GitHub Pages: a participant opens a test link, views the prototype beside a guide, and works through narrated tasks one at a time.
